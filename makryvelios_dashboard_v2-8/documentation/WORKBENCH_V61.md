# Makryvelios Research Workbench 6.1.0-rc1

Additive candidate based on v6.0.0-rc2. No bundled observations, historical research question presets or API keys. Existing numerical engines and bundled NUTS boundaries remain unchanged. British-English interface. This is not a certified research or production system.

## Deployment to the existing test branch

Unzip `Makryvelios_v6_1_GITHUB_upload_only.zip`. Upload the inner `makryvelios_dashboard_v2-8` folder directly to the root of `new-branch`, preserving paths. Commit on `new-branch` only. Streamlit Community Cloud should detect the commit; reboot the existing **test** app if necessary. Do not merge to main before acceptance tests. Main file remains `makryvelios_dashboard_v2-8/app.py`. Keep the existing .streamlit/config.toml. No new secrets are required for the app. Existing user-entered provider API keys remain session-only. The separate optional MCP HTTP process uses administrator-managed credentials, never committed to GitHub.

## Navigation and workflow

Method family and module selector are now above data intake, rather than after AI configuration. AI settings are collapsed. Home provides Prepare / Analyse / Verify & publish action groups and a More tools expander. Existing methods remain accessible from All modules. Blank workspace contains no historical values. Greece GIS retains both NUTS boundary layers and neutral polygons before data upload.

## New modules

18. **Scientific validation**: independent source audit; explicit numeric OLS diagnostics (VIF, Breusch–Pagan, RESET, classical vs HC3 covariance, time-key checks, conditional joint F-test power and ordered Durbin–Watson where meaningful). Endogeneity, identification, leakage, multiplicity and reproducibility are flagged for design-specific review, not automatically certified. Word/Excel and CSV reports available.
19. **Project manager**: portable data-only archive of typed Parquet tables, supporting documents and notes; checksum verification, bounded ZIP sizes, no pickle or path extraction. Restore in the sidebar. Captured tables are archived evidence, not restored model objects. Combined-dataset mapping and prior model settings may need to be selected again. Manually attach supporting documents. New uploads override restored data. Keep archives private.
20. **Peer reviewer**: local structural checklist and optional explicitly authorised provider critique with manuscript excerpts and bounded computed tables. Not a real peer review, novelty verification or acceptance score. Verify against the full manuscript.
21. **Journal intelligence**: Crossref topic-matched article sample grouped by journal. Optional own-key OpenAlex ISSN enrichment; optional direct DOAJ lookups. Metadata and APC must be verified on publisher site; no invented impact factors or predatory labels. Up to ten enriched journal entries. Network calls only on explicit search. No automatic journal formatting or claims of acceptance.
22. **Public finance simulator**: explicit user assumptions, capped absorption draws, reproducible seed, optional proportional regional allocation and map, fixed-rate debt-service stress comparison. Colour and grayscale 600-dpi PNG/TIFF and vector SVG/PDF. This is a scenario model, not a calibrated digital twin, credit-risk model or causal forecast. ITA/GAMS remain separately accessible; no automatic optimisation transfer.
23. **Publication export**: captured result table inventory, CSV, XLSX, DOCX evidence report, LaTeX tables, optional original bibliography JSON / minimal RIS/BibTeX, optional Parquet data, user-attached native figures/drafts/replication scripts. Existing module-specific publication bundles remain authoritative for full figures and model outputs. No fabricated replication scripts or automatic complete paper.
24. **LLM connector setup**: local stdio and optional authenticated Streamable HTTP adapter, with request ID and audit log. Does not install a ChatGPT/Claude connector automatically.

## Separate MCP deployment (administrator)

Local: `pip install -r requirements.txt -r requirements-connector.txt`; set `MKRV_DATA_DIR` to one authorised directory and run `python workbench_connector.py`. The directory is not the Streamlit upload area. User explicitly supplies filenames and variable roles; audit precedes routed computation. HTTP is a separate single-tenant process, not hosted by the Streamlit app. Use one process/container, token and private mounted data directory per user. Generate a random secret (e.g. `python -c 'import secrets; print(secrets.token_urlsafe(48))'`) and store it only in a server-side secret store. Set `MKRV_MCP_TOKEN` and `MKRV_DATA_DIR` in the service environment; launch `uvicorn workbench_connector:remote_app --factory --host 127.0.0.1 --port 8765`. Front with an HTTPS reverse proxy, forwarding the required Authorization header and enforcing request body, rate and execution limits. Validate origin/host configuration with the SDK and proxy; never disable transport security just to make a client connect. No multi-tenant service or OAuth is implemented; only clients supporting the required bearer header are candidates. ChatGPT and Claude connector compatibility and end-to-end handshake remain untested. Never expose port directly or publish authorised datasets. Test only with synthetic data initially.
